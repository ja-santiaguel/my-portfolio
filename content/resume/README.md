# Resume

`resume.html` is the source: one Letter page in the portfolio's type and layout (Oswald titles, Helvetica Neue text from `public/fonts`, uppercase labels, "[ … ]" links, fine rules). Edit it, then export it with `node content/resume/print-resume.cjs`, which uses the installed Firefox (headless, a throwaway profile, nothing to install) and writes both `content/resume/jonathan-santiaguel-resume.pdf` and `public/jonathan-santiaguel-resume.pdf`: the navbar, the menu and the footer link to the public copy (`profile.resume`). **Never with Chrome** (Jonathan removed it after a cyberattack, 2026-11-03).

Don't print from the browser's dialog: opened as a local file, the page can't load its fonts, and Microsoft Print to PDF loses the links. Bold is true Helvetica Neue Bold on ink text only; grey text stays regular (2026-11-04, Jonathan). Check that it's still one page with even space top and bottom after any edit. Every fact comes from the 9-23-26 resume, the case studies or what Jonathan has confirmed (the skills match the About page's toolkit, 2026-11-03); don't add any that aren't confirmed.
